# Phone-Use-Statistics-Analysis
Phone use patterns differ across mobile devices, operating systems, app installs, age, and gender. This program provides statistics, analysis, and visualizations for for the "Mobile Device Usage and User Behavior Dataset" downloaded from Kaggle. This constitutes the capstone project for BAN461: Spring 2026 semester at Wisconsin Lutheran College.

Source for data: https://www.kaggle.com/datasets/valakhorasani/mobile-device-usage-and-user-behavior-dataset?resource=download
